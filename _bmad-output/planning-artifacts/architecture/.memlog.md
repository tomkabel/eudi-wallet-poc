- (decision) ADR-004 rp-kit deployment profile: rp-kit/ is a deployment PROFILE over the existing zkverify binary (documented flag set, systemd/env template, acceptance harness, README), not a wrapper service and not a library. Prevents a second Go service duplicating drain/shed/healthz and integrators assembling the verifier from packages. Profile flag set fixed; -allow-unencrypted-response, -allow-false-predicate, -unsafe-dev-api, -multi-credentials excluded from the profile (negative controls/dev). - (decision) ADR-005 IntendedUseSource + registration-certificate data model: Kotlin interface in domain/presentation next to AgePredicatePolicy; sealed fail-closed result. Absent source = today's blanket refusal with reason intended-use-source-absent; present-but-throwing/timing-out = same refusal with source-error logged, distinct states (Story 4.1). - (decision) ADR-006 signed circuit-list document: JSON, schema tag ee-circuits/1, fields list_version, issued_at, expires_at, min_library_version (Longfellow revision the entries were built against), circuits[] identical to verifier/go/circuits Circuit struct so the id+circuit_hash+params keying is preserved verbatim. - (decision) ADR-007 RP-register lookup contract: Go interface RPRegister with one method IntendedUse(rp) (RegisteredIntendedUse, error); the Go type mirrors ADR-005's Kotlin model field-for-field so the interface proposal (design D3) is one model on both sides. Three distinct fail-closed errors: ErrNoImplementation (unconfigured - refuse, missing prerequisite named), ErrRegisterUnreachable (timeout/5xx - refuse, register error logged), ErrNotFound (register says no such RP - refuse). Refusal never requires a cache hit; cache serves allows only. Bounded cache: TTL default 15m, published in the contract; within-TTL entry may serve an allow without a network round trip (explicitly logged when the register is unreachable: register-unreachable cache-hit-within-ttl); beyond-TTL entry is discarded and treated as absent (refuse) - never a silent allow. Aligns by analogy with EE-REV-007 (cache age bounded and published; beyond it fail closed) though the register is not a status list. File-backed mock ships for the four acceptance cases; the proposal is published even though RIA has no API (OQ-3) and records it is useful even if superseded.
